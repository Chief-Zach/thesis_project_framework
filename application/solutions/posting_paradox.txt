This level is a cross site scripting level that requires the user to execute a randomly named function in the code through
a vulnerable input form. There are no protections in place for inserting any tags or code, but the script that contains
the vulnerable function is an async function, and it is inserted at the end of the DOM, after the user injected code would
run. This means that you have to do a couple workarounds using the solution below:

<script>
document.addEventListener("DOMContentLoaded", async () => {
    await woeiuorf();
});
</script>
